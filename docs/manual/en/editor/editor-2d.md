# 2D Editor

For building game interfaces, HUDs and 2D games: texts, images, rectangles, containers, 9-slices, buttons and videos.

| Function | Description | Shortcut |
|---|---|---|
| Add | Text, Image, Rectangle, Container, Slice 9, Button, Expand, Video; Import w3dui. | Add menu |
| Select | A click picks (dragging moves); <kbd>Shift</kbd>+click adds; clicking on empty space deselects. | Click; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Move / Rotate / Scale | <kbd>X</kbd> / <kbd>Y</kbd> lock the axis; you can type the value. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Resize | The grab handles of the active element. | Drag |
| Duplicate / Delete | Offset copy, left grabbed / deletes with confirmation. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Set Parent / Clear Parent | The selection becomes a child of the active element, or hangs from the UI again. | Object menu |
| 2D Cursor | Placed with <kbd>Shift</kbd>+click on empty space. | <kbd>Shift</kbd>+click |
| Game View | The canvas looks exactly as it will on the device, without guides. | <kbd>Num0</kbd> (<kbd>Esc</kbd> exits) |
| Frame / Zoom 1:1…4:1 | Frames the selection; exact pixel-to-pixel zoom. | <kbd>Num.</kbd> / View menu |
