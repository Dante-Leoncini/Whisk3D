# Armatures

## Armature Edit Mode

| Function | Description | Shortcut |
|---|---|---|
| Select | Picks a bone tip or the whole bone; dragging moves it right away. | Click; <kbd>Shift</kbd> adds |
| All / None | Selects or deselects all the bones. | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extrude Bone | Creates a new bone from each selected tip. | <kbd>E</kbd> |
| Move / Rotate / Scale | With axes and planes as usual. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplicate | Copies the bones and leaves them grabbed. | <kbd>Shift+D</kbd> |
| Delete | Deletes the bones (their children move to the grandparent). | <kbd>X</kbd> or <kbd>Delete</kbd> |
| Set Parent | Keep Offset or Connected. | <kbd>Ctrl+P</kbd> |
| Disconnect / Clear Parent | Releases the bone from its parent. | <kbd>Alt+P</kbd> |

## Pose Mode

Armatures only. Used to pose and animate.

| Function | Description | Shortcut |
|---|---|---|
| Select bone | Picks a bone. | Click; <kbd>Shift</kbd> adds |
| Move / Rotate / Scale | Poses the selected bones. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Clear Location / Rotation / Scale | Returns the bone to its rest pose in that channel. | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Insert Keyframe | Stores the pose at the current frame. | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
