# The interface

The window is divided into **viewports** (panels). Each one can be of one type: 3D Viewport, Outliner, Properties, UV Editor, Timeline, 2D Editor, Console or Script Editor (IDE).

| Function | Description | How to use it |
|---|---|---|
| Active viewport | The viewport that receives the keyboard. It is marked with a green border and follows the pointer: keys go to the panel under the mouse. | Move the mouse over it. On touch screens, tap it. |
| Change the viewport type | Turns the panel into another type of editor. | Button in the left corner of its top bar. |
| Split in Columns / Rows | Splits the viewport in two. | Corner button → Split in Columns / Split in Rows. |
| Maximize / Minimize | Enlarges the viewport to fill the whole window, and puts it back in its place. | Corner button → Maximize. |
| Resize | Changes the size of the panels. | Drag the border between two viewports (or the corner). |
| Top bar | The viewport's menus. If it doesn't fit, it scrolls. | Mouse wheel or drag with your finger. |
| Keyboard menu bar | Opens the active viewport's menu bar so you can go through it with the arrows. | <kbd>M</kbd> (in Edit Mode, <kbd>M</kbd> is Merge). |
| Undo / Redo | Steps the last action back or forward. | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> or <kbd>Ctrl+Shift+Z</kbd>; arrows in the bottom bar. |
| Save project | Saves the open .w3d (if it's new, it asks for a name). | <kbd>Ctrl+S</kbd>, or Properties → File/Render tab → File card (see [The project](proyecto.md)). |
| Fullscreen | Enters and leaves fullscreen. | <kbd>F11</kbd>. On Android it's automatic if the phone has no notch. |
| Play / Pause | Plays the animation (or the game) from any panel. | <kbd>Space</kbd> or the Play button in the timeline. |

**On Android**: in portrait the layout is the 3D Viewport on top and Properties below; in landscape the timeline is added. When the on-screen keyboard opens (for example in the script editor), the active viewport is maximized in the visible area and goes back to its place when the keyboard closes.
