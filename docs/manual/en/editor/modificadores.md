# Modifiers

They're added in Properties (Modifiers card → Add) and change the mesh without destroying it: you can turn them off, reorder them or apply (bake) them whenever you want.

| Modifier | Description |
|---|---|
| Mirror | Reflects the mesh on X, Y and/or Z (or relative to another object). It can weld the center and keep it from crossing over. |
| Array | Makes copies in a row: count, relative offset (based on the size), constant offset (in meters) and optionally based on another object (cumulative: spirals, stairs). It can weld the copies. |
| Subdivision Surface | Smooths the mesh by subdividing it (levels for the viewport and for the render). |
| Boolean | Intersect, Union or Difference with another object. |
| Screw | Spins a profile around an axis (screws, vases, springs). |
| Armature | Deforms the mesh with an armature. |
| Culling | Optimization: doesn't draw the parts that can't be seen from the camera. |
