# What is Whisk3D

Whisk3D is a 3D editor and game engine built from scratch. With it you can model, paint, animate, build 2D interfaces and program games in Lua. It runs on **PC** (Linux, Windows), **Android**, the **browser** (Web) and the **Nokia N95** (Symbian).

All your work is saved in a `.w3d` project file. It holds the scene and also the resources: textures (`texturas/`), scripts (`scripts/`), sounds, scenes, prefabs. A resource can live **inside** the .w3d or **outside**, as a separate file on disk; the "Save inside the .w3d" and "Save outside the .w3d" menus move it from one place to the other.

> [!NOTE]
> This manual describes what Whisk3D can do today. The function names are the ones shown in the editor in English. The keys listed are the defaults: they can be changed in [Keyboard Shortcuts](atajos.md).
