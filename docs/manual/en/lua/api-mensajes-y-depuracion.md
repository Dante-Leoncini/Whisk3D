# Messages and debugging

| Function | What it does |
|---|---|
| `print(...)` | Writes to the engine's log, not to the screen. |
| `info(msg)`, `aviso(msg)`, `error(msg)` | Info, warning or error messages in the log. `error` does **not** stop the script. |
| `depurar(msg)`, `esDebug()` | Messages only in debug builds. |
| `logCantidad()`, `logLinea(i)` | Read the log from the game (a console of your own). |
