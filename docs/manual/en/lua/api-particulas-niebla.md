# Particles, fog and visibility

| Function | What it does |
|---|---|
| `emitir(obj [, n])`, `setEmitiendo(obj, bool)` | A burst of particles, or turning an emitter on/off. |
| `niebla(obj)`, `setNiebla(obj, densidad [, r, g, b, inicio, fin])` | Read and change the fog. |
| `setSector`, `visCelda`, `setVisAncla`, `setVisCurvaT`, `setLote` | Advanced control over which parts of the level get drawn. |
