# What Lua is and what it's used for in Whisk3D

Lua is a small, fast programming language that's easy to learn. Whisk3D comes with **Lua 5.4** built in and uses it for the game *logic*: moving a character with the keys, keeping score, opening a menu, playing a sound when something collides.

Scripts are written in Whisk3D's **Script Editor** (or in any text editor) and saved as `.lua` files, usually inside the `.w3d` project (in its `scripts/` folder). They only run while the game is running: with the timeline in **Game** mode and **Play**, or in a built game.
