# Editor 2D

Para armar interfaces de juego, HUD y juegos 2D: textos, imágenes, rectángulos, contenedores, slice 9, botones y videos.

| Función | Descripción | Atajo |
|---|---|---|
| Añadir | Texto, imagen, rectángulo, contenedor, slice 9, botón, expandir, video; Importar w3dui. | Menú Añadir |
| Seleccionar | Click elige (arrastrar mueve); <kbd>Shift</kbd>+click suma; click en el vacío deselecciona. | Click; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Mover / Rotar / Escalar | <kbd>X</kbd> / <kbd>Y</kbd> bloquean el eje; se puede tipear el valor. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Redimensionar | Los puntos de agarre del elemento activo. | Arrastrar |
| Duplicar / Borrar | Copia desplazada y agarrada / borra con confirmación. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Emparentar / Desemparentar | La selección pasa a ser hija del activo, o vuelve a colgar del UI. | Menú Objeto |
| Cursor 2D | Se coloca con <kbd>Shift</kbd>+click en el vacío. | <kbd>Shift</kbd>+click |
| Vista de juego | El lienzo se ve exactamente como en el dispositivo, sin guías. | <kbd>Num0</kbd> (<kbd>Esc</kbd> sale) |
| Encuadrar / Zoom 1:1…4:1 | Encuadra la selección; zoom exacto píxel a píxel. | <kbd>Num.</kbd> / menú Vista |
