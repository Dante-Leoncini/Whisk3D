# Esqueletos

## Modo Edición de esqueleto

| Función | Descripción | Atajo |
|---|---|---|
| Seleccionar | Elige una punta del hueso o el hueso entero; arrastrar lo mueve al toque. | Click; <kbd>Shift</kbd> suma |
| Todo / Ninguno | Selecciona o deselecciona todos los huesos. | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extruir hueso | Crea un hueso nuevo desde cada punta seleccionada. | <kbd>E</kbd> |
| Mover / Rotar / Escalar | Con ejes y planos como siempre. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplicar | Copia los huesos y los deja agarrados. | <kbd>Shift+D</kbd> |
| Borrar | Borra los huesos (sus hijos pasan al abuelo). | <kbd>X</kbd> o <kbd>Supr</kbd> |
| Emparentar | Mantener offset o conectado. | <kbd>Ctrl+P</kbd> |
| Desconectar / Desemparentar | Suelta el hueso de su padre. | <kbd>Alt+P</kbd> |

## Modo Pose

Solo para esqueletos. Sirve para posar y animar.

| Función | Descripción | Atajo |
|---|---|---|
| Seleccionar hueso | Elige un hueso. | Click; <kbd>Shift</kbd> suma |
| Mover / Rotar / Escalar | Posa los huesos seleccionados. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Limpiar posición / rotación / escala | Devuelve el hueso a su pose de reposo en ese canal. | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Insertar keyframe | Guarda la pose en el frame actual. | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
