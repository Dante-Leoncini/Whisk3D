# La interfaz

La ventana se divide en **viewports** (paneles). Cada uno puede ser de un tipo: Vista 3D, Outliner, Propiedades, Editor UV, Línea de tiempo, Editor 2D, Consola o Editor de scripts (IDE).

| Función | Descripción | Cómo se usa |
|---|---|---|
| Viewport activo | El viewport que recibe el teclado. Se marca con un borde verde y sigue al puntero: las teclas van al panel que está bajo el mouse. | Mover el mouse encima. En táctil, tocarlo. |
| Cambiar el tipo de viewport | Convierte el panel en otro tipo de editor. | Botón de la esquina izquierda de su barra superior. |
| Dividir en columnas / filas | Parte el viewport en dos. | Botón de la esquina → Dividir en columnas / Dividir en filas. |
| Maximizar / Minimizar | Agranda el viewport a toda la ventana, y lo devuelve a su lugar. | Botón de la esquina → Maximizar. |
| Redimensionar | Cambia el tamaño de los paneles. | Arrastrar el borde entre dos viewports (o la esquina). |
| Barra superior | Los menús del viewport. Si no entra, se desplaza. | Rueda del mouse o arrastrar con el dedo. |
| Barra de menús por teclado | Abre la barra de menús del viewport activo para recorrerla con las flechas. | <kbd>M</kbd> (en Modo Edición, <kbd>M</kbd> es Fusionar). |
| Deshacer / Rehacer | Vuelve atrás o adelante la última acción. | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> o <kbd>Ctrl+Shift+Z</kbd>; flechas de la barra inferior. |
| Guardar proyecto | Guarda el .w3d abierto (si es nuevo, pide nombre). | <kbd>Ctrl+S</kbd>, o Propiedades → pestaña Archivo/Render → tarjeta Archivo (ver [El proyecto](proyecto.md)). |
| Pantalla completa | Entra y sale de pantalla completa. | <kbd>F11</kbd>. En Android es automática si el teléfono no tiene notch. |
| Reproducir / Pausa | Reproduce la animación (o el juego) desde cualquier panel. | <kbd>Espacio</kbd> o el botón Play de la línea de tiempo. |

**En Android**: en vertical el layout es Vista 3D arriba y Propiedades abajo; en horizontal se suma la línea de tiempo. Cuando se abre el teclado en pantalla (por ejemplo en el editor de scripts), el viewport activo se maximiza en la parte visible y vuelve a su lugar al cerrarlo.
