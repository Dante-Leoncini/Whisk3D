# Modificadores

Se agregan en Propiedades (tarjeta Modificadores → Añadir) y cambian la malla sin destruirla: se pueden apagar, reordenar o aplicar (hornear) cuando se quiera.

| Modificador | Descripción |
|---|---|
| Espejo | Refleja la malla en X, Y y/o Z (o respecto de otro objeto). Puede soldar el centro y evitar que se cruce. |
| Array | Hace copias en fila: cantidad, desplazamiento relativo (según el tamaño), desplazamiento constante (en metros) y opcionalmente según otro objeto (acumulativo: espirales, escaleras). Puede soldar las copias. |
| Superficie de subdivisión | Suaviza la malla subdividiéndola (niveles para la vista y para el render). |
| Booleano | Intersección, unión o diferencia con otro objeto. |
| Screw | Gira un perfil alrededor de un eje (tornillos, jarrones, resortes). |
| Esqueleto | Deforma la malla con un esqueleto. |
| Culling | Optimización: no dibuja las partes que no se ven desde la cámara. |
