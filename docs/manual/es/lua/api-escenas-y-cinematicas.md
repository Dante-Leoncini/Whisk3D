# Escenas y cinemáticas

| Función | Qué hace |
|---|---|
| `cambiarEscena(nombre [, reiniciar])` | Pasa a otra escena (menú, nivel 2…) al final del cuadro. |
| `reproducirEscena(nombre [, "funcion"])` | Reproduce una escena 3D como cinemática con el juego en pausa; al terminar llama a esa función. |
| `pararEscena3D()`, `escenaReproduciendo()` | Corta la cinemática / dice cuál se está viendo. |
| `dibujar3D([on])` | Apaga o prende todo el 3D (por ejemplo, detrás de un menú opaco). |
