# Partículas, niebla y visibilidad

| Función | Qué hace |
|---|---|
| `emitir(obj [, n])`, `setEmitiendo(obj, bool)` | Una ráfaga de partículas, o prender/apagar un emisor. |
| `niebla(obj)`, `setNiebla(obj, densidad [, r, g, b, inicio, fin])` | Leer y cambiar la niebla. |
| `setSector`, `visCelda`, `setVisAncla`, `setVisCurvaT`, `setLote` | Control avanzado de qué partes del nivel se dibujan. |
