# 2D Editor

Pour construire des interfaces de jeu, des HUD et des jeux 2D : textes, images, rectangles, conteneurs, slice 9, boutons et vidéos.

| Fonction | Description | Raccourci |
|---|---|---|
| Add | Text, Image, Rectangle, Container, Slice 9, Button, Expand, Video ; Import w3dui. | Menu Add |
| Select | Un clic choisit (glisser déplace) ; <kbd>Shift</kbd>+clic ajoute ; un clic dans le vide désélectionne. | Clic ; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Move / Rotate / Scale | <kbd>X</kbd> / <kbd>Y</kbd> verrouillent l'axe ; on peut taper la valeur. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Redimensionner | Les poignées de l'élément actif. | Glisser |
| Duplicate / Delete | Copie décalée et saisie / suppression avec confirmation. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Set Parent / Clear Parent | La sélection devient enfant de l'élément actif, ou se rattache de nouveau à l'UI. | Menu Object |
| 2D Cursor | Se place avec <kbd>Shift</kbd>+clic dans le vide. | <kbd>Shift</kbd>+clic |
| Game View | Le canevas s'affiche exactement comme sur l'appareil, sans repères. | <kbd>Num0</kbd> (<kbd>Esc</kbd> pour sortir) |
| Cadrer / Zoom 1:1…4:1 | Cadre la sélection ; zoom exact pixel pour pixel. | <kbd>Num.</kbd> / menu View |
