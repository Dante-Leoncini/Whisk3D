# Armatures

## Edit Mode (armature)

| Fonction | Description | Raccourci |
|---|---|---|
| Select | Choisit une extrémité de l'os ou l'os entier ; le faire glisser le déplace aussitôt. | Clic ; <kbd>Shift</kbd> ajoute |
| All / None | Sélectionne ou désélectionne tous les os. | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extrude Bone | Crée un nouvel os depuis chaque extrémité sélectionnée. | <kbd>E</kbd> |
| Move / Rotate / Scale | Avec les axes et les plans, comme d'habitude. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplicate | Copie les os et les laisse saisis. | <kbd>Shift+D</kbd> |
| Delete | Supprime les os (leurs enfants passent au grand-parent). | <kbd>X</kbd> ou <kbd>Delete</kbd> |
| Set Parent | Keep Offset ou Connected. | <kbd>Ctrl+P</kbd> |
| Disconnect / Clear Parent | Détache l'os de son parent. | <kbd>Alt+P</kbd> |

## Pose Mode

Uniquement pour les armatures. Sert à poser et à animer.

| Fonction | Description | Raccourci |
|---|---|---|
| Sélectionner un os | Choisit un os. | Clic ; <kbd>Shift</kbd> ajoute |
| Move / Rotate / Scale | Pose les os sélectionnés. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Clear Location / Rotation / Scale | Remet l'os dans sa pose de repos pour ce canal. | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Insert Keyframe | Enregistre la pose à la frame actuelle. | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
