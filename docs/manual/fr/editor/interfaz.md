# L'interface

La fenêtre est divisée en **viewports** (panneaux). Chacun peut être d'un type : 3D Viewport, Outliner, Properties, UV Editor, Timeline, 2D Editor, Console ou Script Editor (IDE).

| Fonction | Description | Utilisation |
|---|---|---|
| Viewport actif | Le viewport qui reçoit le clavier. Il est signalé par une bordure verte et suit le pointeur : les touches vont au panneau qui se trouve sous la souris. | Passez la souris dessus. En tactile, touchez-le. |
| Changer le type de viewport | Transforme le panneau en un autre type d'éditeur. | Bouton du coin gauche de sa barre supérieure. |
| Split in Columns / Rows | Coupe le viewport en deux. | Bouton du coin → Split in Columns / Split in Rows. |
| Maximize / Minimize | Agrandit le viewport à toute la fenêtre, puis le remet à sa place. | Bouton du coin → Maximize. |
| Redimensionner | Change la taille des panneaux. | Faites glisser la bordure entre deux viewports (ou le coin). |
| Barre supérieure | Les menus du viewport. Si elle ne tient pas, elle défile. | Molette de la souris ou glisser du doigt. |
| Barre de menus au clavier | Ouvre la barre de menus du viewport actif pour la parcourir avec les flèches. | <kbd>M</kbd> (en Edit Mode, <kbd>M</kbd> correspond à Merge). |
| Undo / Redo | Annule ou rétablit la dernière action. | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> ou <kbd>Ctrl+Shift+Z</kbd> ; flèches de la barre inférieure. |
| Save project | Enregistre le .w3d ouvert (s'il est nouveau, demande un nom). | <kbd>Ctrl+S</kbd>, ou Properties → onglet File/Render → carte File (voir [Le projet](proyecto.md)). |
| Fullscreen | Entre en plein écran et en sort. | <kbd>F11</kbd>. Sur Android, c'est automatique si le téléphone n'a pas d'encoche. |
| Play / Pause | Lit l'animation (ou le jeu) depuis n'importe quel panneau. | <kbd>Space</kbd> ou le bouton Play de la Timeline. |

**Sur Android** : en portrait, la disposition place le 3D Viewport en haut et Properties en bas ; en paysage, la Timeline s'y ajoute. Quand le clavier à l'écran s'ouvre (par exemple dans le Script Editor), le viewport actif s'agrandit dans la partie visible et reprend sa place quand le clavier se ferme.
