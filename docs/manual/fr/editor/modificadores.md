# Modificateurs

Ils s'ajoutent dans Properties (carte Modifiers → Add) et modifient le maillage sans le détruire : vous pouvez les désactiver, les réordonner ou les appliquer (« cuire ») quand vous le souhaitez.

| Modificateur | Description |
|---|---|
| Mirror | Reflète le maillage en X, Y et/ou Z (ou par rapport à un autre objet). Peut souder le centre et éviter qu'il ne se croise. |
| Array | Fait des copies en rangée : nombre, décalage relatif (selon la taille), décalage constant (en mètres) et, en option, selon un autre objet (cumulatif : spirales, escaliers). Peut souder les copies. |
| Subdivision Surface | Lisse le maillage en le subdivisant (niveaux pour la vue et pour le rendu). |
| Boolean | Intersection, union ou différence avec un autre objet. |
| Screw | Fait tourner un profil autour d'un axe (vis, vases, ressorts). |
| Armature | Déforme le maillage avec une armature. |
| Culling | Optimisation : ne dessine pas les parties invisibles depuis la caméra. |
