# Autres fonctions du 3D Viewport

| Fonction | Description | Utilisation |
|---|---|---|
| Camera View | Regarde à travers la caméra active avec un cadre de la taille du rendu. À l'intérieur, la molette ou le pincement font un zoom d'inspection sans déplacer la caméra. | <kbd>Num0</kbd> |
| Local View | Isole la sélection (avec ses parents et ses enfants) ; recommencer restaure tout. | <kbd>/</kbd> |
| 3D Cursor | Point où naissent les nouveaux objets ; il sert aussi de pivot. Il se place avec le menu Snap (<kbd>Shift+S</kbd>). | <kbd>Shift+S</kbd> |
| Ray Tracing | Rendu réaliste avec ombres douces, transparences, reflets (rugosité et aspect métallique du matériau) et normal maps. Il s'active dans Properties → Render et s'affiche en Render Preview ; l'image se complète petit à petit. | Properties → Render |
| Mode jeu | Avec l'animation « Game » en lecture (Play), les clics et les touches vont au jeu. <kbd>Esc</kbd> met en pause. | Boutons Play / Stop de la barre |
