# Qu'est-ce que Whisk3D ?

Whisk3D est un éditeur 3D et un moteur de jeu créé de zéro. Il permet de modéliser, de peindre, d'animer, de construire des interfaces 2D et de programmer des jeux en Lua. Il fonctionne sur **PC** (Linux, Windows), **Android**, le **navigateur** (Web) et le **Nokia N95** (Symbian).

Tout le travail est enregistré dans un fichier de projet `.w3d`. Il contient la scène, mais aussi les ressources : textures (`texturas/`), scripts (`scripts/`), sons, scènes, prefabs. Une ressource peut se trouver **dans** le .w3d ou **en dehors**, comme fichier séparé sur le disque ; les menus « Save inside the .w3d » et « Save outside the .w3d » la font passer de l'un à l'autre.

> [!NOTE]
> Ce manuel décrit ce que Whisk3D sait faire aujourd'hui. Les noms des fonctions sont ceux affichés dans l'éditeur en anglais, car l'éditeur n'est pas encore disponible en français. Les touches indiquées sont celles par défaut : vous pouvez les modifier dans [Raccourcis clavier](atajos.md).
