# Scènes et cinématiques

| Fonction | Ce qu'elle fait |
|---|---|
| `cambiarEscena(nombre [, reiniciar])` | Passe à une autre scène (menu, niveau 2…) à la fin de l'image. |
| `reproducirEscena(nombre [, "funcion"])` | Lit une scène 3D comme cinématique, avec le jeu en pause ; à la fin, appelle cette fonction. |
| `pararEscena3D()`, `escenaReproduciendo()` | Interrompt la cinématique / indique celle qui est en cours. |
| `dibujar3D([on])` | Désactive ou active toute la 3D (par exemple, derrière un menu opaque). |
