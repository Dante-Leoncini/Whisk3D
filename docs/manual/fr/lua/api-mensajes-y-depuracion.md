# Messages et débogage

| Fonction | Ce qu'elle fait |
|---|---|
| `print(...)` | Écrit dans le journal (log) du moteur, pas à l'écran. |
| `info(msg)`, `aviso(msg)`, `error(msg)` | Messages d'information, d'avertissement ou d'erreur dans le journal. `error` n'interrompt **pas** le script. |
| `depurar(msg)`, `esDebug()` | Messages uniquement dans les versions de débogage. |
| `logCantidad()`, `logLinea(i)` | Lire le journal depuis le jeu (une console à vous). |
