# Particules, brouillard et visibilité

| Fonction | Ce qu'elle fait |
|---|---|
| `emitir(obj [, n])`, `setEmitiendo(obj, bool)` | Une rafale de particules, ou activer/désactiver un émetteur. |
| `niebla(obj)`, `setNiebla(obj, densidad [, r, g, b, inicio, fin])` | Lire et modifier le brouillard. |
| `setSector`, `visCelda`, `setVisAncla`, `setVisCurvaT`, `setLote` | Contrôle avancé des parties du niveau qui sont dessinées. |
