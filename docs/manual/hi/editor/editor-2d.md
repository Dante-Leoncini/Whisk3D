# 2D Editor

गेम के इंटरफ़ेस, HUD और 2D गेम बनाने के लिए: टेक्स्ट, इमेज, आयत, कंटेनर, slice 9, बटन और वीडियो।

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| Add | Text, Image, Rectangle, Container, Slice 9, Button, Expand, Video; Import w3dui। | Add मेनू |
| Select | क्लिक से चुनें (ड्रैग करने पर मूव होता है); <kbd>Shift</kbd>+क्लिक जोड़ता है; खाली जगह पर क्लिक करने से चयन हट जाता है। | क्लिक; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Move / Rotate / Scale | <kbd>X</kbd> / <kbd>Y</kbd> अक्ष लॉक करते हैं; आप वैल्यू टाइप भी कर सकते हैं। | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| आकार बदलना | सक्रिय एलिमेंट के पकड़ने वाले पॉइंट। | ड्रैग करें |
| Duplicate / Delete | खिसकी हुई और पकड़ी हुई कॉपी / पुष्टि के साथ डिलीट करता है। | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Set Parent / Clear Parent | चयन सक्रिय एलिमेंट का चाइल्ड बन जाता है, या फिर से UI के नीचे आ जाता है। | Object मेनू |
| 2D Cursor | खाली जगह पर <kbd>Shift</kbd>+क्लिक से रखा जाता है। | <kbd>Shift</kbd>+क्लिक |
| Game View | कैनवास बिल्कुल वैसा दिखता है जैसा डिवाइस पर, बिना गाइड के। | <kbd>Num0</kbd> (<kbd>Esc</kbd> से बाहर आएँ) |
| Frame Selected / Zoom 1:1…4:1 | चयन को फ़्रेम करता है; पिक्सेल-दर-पिक्सेल सटीक ज़ूम। | <kbd>Num.</kbd> / View मेनू |
