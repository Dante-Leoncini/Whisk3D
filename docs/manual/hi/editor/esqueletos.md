# आर्मेचर

## Armature Edit Mode

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| Select | बोन का एक सिरा या पूरी बोन चुनता है; ड्रैग करने पर वह तुरंत मूव हो जाती है। | क्लिक; <kbd>Shift</kbd> जोड़ता है |
| All / None | सभी बोन को चुनता है या उनका चयन हटाता है। | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extrude Bone | हर चुने हुए सिरे से एक नई बोन बनाता है। | <kbd>E</kbd> |
| Move / Rotate / Scale | हमेशा की तरह अक्षों और प्लेन के साथ। | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplicate | बोन की कॉपी बनाता है और उन्हें पकड़े रखता है। | <kbd>Shift+D</kbd> |
| Delete | बोन डिलीट करता है (उनकी चाइल्ड बोन दादा-बोन से जुड़ जाती हैं)। | <kbd>X</kbd> या <kbd>Delete</kbd> |
| Set Parent | Keep Offset या Connected। | <kbd>Ctrl+P</kbd> |
| Disconnect / Clear Parent | बोन को उसके पैरेंट से अलग करता है। | <kbd>Alt+P</kbd> |

## Pose Mode

सिर्फ़ आर्मेचर के लिए। यह पोज़ देने और एनिमेट करने के काम आता है।

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| बोन चुनना | एक बोन चुनता है। | क्लिक; <kbd>Shift</kbd> जोड़ता है |
| Move / Rotate / Scale | चुनी हुई बोन को पोज़ देता है। | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Clear Location / Rotation / Scale | उस चैनल में बोन को उसके रेस्ट पोज़ पर लौटा देता है। | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Insert Keyframe | मौजूदा फ़्रेम में पोज़ सेव करता है। | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
