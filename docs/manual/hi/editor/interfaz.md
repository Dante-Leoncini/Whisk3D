# इंटरफ़ेस

विंडो कई **व्यूपोर्ट** (पैनल) में बँटी होती है। हर व्यूपोर्ट इनमें से किसी एक प्रकार का हो सकता है: 3D Viewport, Outliner, Properties, UV Editor, Timeline, 2D Editor, Console या Script Editor (IDE)।

| फ़ंक्शन | विवरण | कैसे इस्तेमाल करें |
|---|---|---|
| सक्रिय व्यूपोर्ट | वह व्यूपोर्ट जिसे कीबोर्ड का इनपुट मिलता है। उसके चारों ओर हरी बॉर्डर होती है और वह पॉइंटर के साथ बदलता है: कुंजियाँ उसी पैनल में जाती हैं जो माउस के नीचे है। | माउस को उसके ऊपर ले जाएँ। टच पर, उसे टैप करें। |
| व्यूपोर्ट का प्रकार बदलना | पैनल को किसी दूसरे प्रकार के एडिटर में बदल देता है। | उसकी ऊपरी बार के बाएँ कोने वाला बटन। |
| Split in Columns / Rows | व्यूपोर्ट को दो हिस्सों में बाँटता है। | कोने वाला बटन → Split in Columns / Split in Rows। |
| Maximize / Minimize | व्यूपोर्ट को पूरी विंडो जितना बड़ा करता है, और फिर उसे उसकी जगह वापस लाता है। | कोने वाला बटन → Maximize। |
| आकार बदलना | पैनलों का आकार बदलता है। | दो व्यूपोर्ट के बीच की बॉर्डर (या कोने) को ड्रैग करें। |
| ऊपरी बार | व्यूपोर्ट के मेनू। अगर पूरी जगह न हो, तो यह स्क्रॉल होती है। | माउस व्हील, या उंगली से ड्रैग करें। |
| कीबोर्ड से मेनू बार | सक्रिय व्यूपोर्ट की मेनू बार खोलता है, ताकि आप ऐरो कुंजियों से उसमें घूम सकें। | <kbd>M</kbd> (Edit Mode में <kbd>M</kbd> का मतलब Merge है)। |
| Undo / Redo | पिछली क्रिया को वापस लेता है या दोबारा करता है। | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> या <kbd>Ctrl+Shift+Z</kbd>; निचली बार के ऐरो। |
| Save project | खुली हुई .w3d को सेव करता है (अगर वह नई है, तो नाम पूछता है)। | <kbd>Ctrl+S</kbd>, या Properties → File/Render टैब → File कार्ड ([प्रोजेक्ट](proyecto.md) देखें)। |
| Fullscreen | फ़ुल स्क्रीन में जाता है और उससे बाहर आता है। | <kbd>F11</kbd>। Android पर, अगर फ़ोन में notch नहीं है, तो यह अपने-आप होता है। |
| Play / Pause | किसी भी पैनल से एनिमेशन (या गेम) चलाता है। | <kbd>Space</kbd> या Timeline का Play बटन। |

**Android पर**: पोर्ट्रेट में लेआउट ऊपर 3D Viewport और नीचे Properties होता है; लैंडस्केप में Timeline भी जुड़ जाती है। जब ऑन-स्क्रीन कीबोर्ड खुलता है (जैसे Script Editor में), तो सक्रिय व्यूपोर्ट दिखने वाले हिस्से में मैक्सिमाइज़ हो जाता है और कीबोर्ड बंद होने पर अपनी जगह लौट आता है।
