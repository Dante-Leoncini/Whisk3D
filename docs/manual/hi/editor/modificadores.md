# Modifiers

इन्हें Properties में जोड़ा जाता है (Modifiers कार्ड → Add) और ये मेश को नष्ट किए बिना उसे बदलते हैं: आप जब चाहें इन्हें बंद कर सकते हैं, इनका क्रम बदल सकते हैं या इन्हें लागू (बेक) कर सकते हैं।

| मॉडिफ़ायर | विवरण |
|---|---|
| Mirror | मेश को X, Y और/या Z में (या किसी दूसरे ऑब्जेक्ट के सापेक्ष) प्रतिबिंबित करता है। यह बीच वाले हिस्से को जोड़ सकता है और मेश को आर-पार जाने से रोक सकता है। |
| Array | एक पंक्ति में कॉपियाँ बनाता है: संख्या, सापेक्ष ऑफ़सेट (साइज़ के हिसाब से), स्थिर ऑफ़सेट (मीटर में) और चाहें तो किसी दूसरे ऑब्जेक्ट के हिसाब से (एक के ऊपर एक जुड़ता हुआ: सर्पिल, सीढ़ियाँ)। यह कॉपियों को आपस में जोड़ सकता है। |
| Subdivision Surface | मेश को सबडिवाइड करके स्मूद बनाता है (व्यू और रेंडर के लिए अलग-अलग लेवल)। |
| Boolean | किसी दूसरे ऑब्जेक्ट के साथ Intersect, Union या Difference। |
| Screw | किसी प्रोफ़ाइल को एक अक्ष के चारों ओर घुमाता है (पेंच, फूलदान, स्प्रिंग)। |
| Armature | मेश को आर्मेचर से मोड़ता है। |
| Culling | ऑप्टिमाइज़ेशन: कैमरे से न दिखने वाले हिस्सों को ड्रॉ नहीं करता। |
