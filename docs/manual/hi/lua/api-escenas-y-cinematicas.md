# सीन और सिनेमैटिक

| फ़ंक्शन | क्या करता है |
|---|---|
| `cambiarEscena(nombre [, reiniciar])` | फ़्रेम के अंत में दूसरे सीन (मेनू, लेवल 2…) पर चला जाता है। |
| `reproducirEscena(nombre [, "funcion"])` | गेम को पॉज़ करके किसी 3D सीन को सिनेमैटिक की तरह चलाता है; ख़त्म होने पर उस फ़ंक्शन को कॉल करता है। |
| `pararEscena3D()`, `escenaReproduciendo()` | सिनेमैटिक रोकता है / बताता है कि कौन-सा चल रहा है। |
| `dibujar3D([on])` | पूरे 3D को बंद या चालू करता है (जैसे किसी अपारदर्शी मेनू के पीछे)। |
