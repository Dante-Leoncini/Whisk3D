# पार्टिकल, फ़ॉग और दृश्यता

| फ़ंक्शन | क्या करता है |
|---|---|
| `emitir(obj [, n])`, `setEmitiendo(obj, bool)` | पार्टिकल की एक बौछार, या किसी एमिटर को चालू/बंद करना। |
| `niebla(obj)`, `setNiebla(obj, densidad [, r, g, b, inicio, fin])` | फ़ॉग पढ़ना और बदलना। |
| `setSector`, `visCelda`, `setVisAncla`, `setVisCurvaT`, `setLote` | लेवल के कौन-से हिस्से ड्रॉ होंगे, इस पर एडवांस कंट्रोल। |
