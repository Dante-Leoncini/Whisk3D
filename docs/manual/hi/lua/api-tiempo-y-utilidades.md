# समय, रैंडम और उपयोगी फ़ंक्शन

| फ़ंक्शन | क्या करता है |
|---|---|
| `azar() → 0..1`, `azar(min, max) → entero` | रैंडम संख्याएँ। |
| `relojMs() → ms` | मिलीसेकंड, यह मापने के लिए कि किसी काम में कितना समय लगता है। |
| `perfilLua(cuadros [, etiqueta])` | मापता है कि स्क्रिप्ट के कौन-से हिस्से धीमे हैं (`perfilLua(0)` इसे बंद करता है)। |
| `lineaCrear(nombre, puntos)`, `lineaPunto(id, s)` | इंजन द्वारा गणना किया गया एक स्मूद बंद कर्व (रास्तों के लिए)। |

"शुरू होने से अब तक का समय" बताने वाला कोई फ़ंक्शन नहीं है: किसी वेरिएबल में `dt` जोड़ते रहें।
