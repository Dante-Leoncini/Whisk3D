# 3D में मूव, रोटेट और स्केल करना

| फ़ंक्शन | क्या करता है |
|---|---|
| `posicion(obj) → x, y, z` | वह कहाँ है। |
| `setPosicion(obj, x, y, z)` | उसे एक सटीक जगह पर रखता है (फ़िज़िक्स को अनदेखा करता है)। |
| `mover(obj, dx, dy, dz)` | उसे उसकी मौजूदा जगह से खिसकाता है (इसे `dt` के साथ इस्तेमाल करें)। |
| `rotacion(obj) → x, y, z` | उसका रोटेशन, डिग्री में। |
| `setRotacion(obj, x, y, z [, orden])` | सटीक रोटेशन; `orden` उदाहरण के लिए `"YXZ"` होता है (डिफ़ॉल्ट `"XYZ"`)। |
| `girar(obj, dx, dy, dz)` | उसे उसके अपने अक्षों पर घुमाता है। |
| `girarHacia(obj, dx, dz [, factor])` | उसे फ़र्श पर किसी दिशा की ओर धीरे-धीरे घुमाता है। |
| `mirarA(obj, x, y, z)` | उसे किसी पॉइंट की ओर करता है (कैमरे का सामने वाला हिस्सा)। |
| `escala(obj) → sx, sy, sz` | उसका स्केल। |
| `setEscala(obj, s [, sy, sz])` | सटीक स्केल; सिर्फ़ एक संख्या देने पर सभी दिशाओं में बराबर स्केल करता है। |
| `escalar(obj, f)` | मौजूदा स्केल को गुणा करता है। |
| `puntoMundo(obj, x, y, z) → x, y, z` | ऑब्जेक्ट के किसी पॉइंट को वर्ल्ड कोऑर्डिनेट में बदलता है। |
| `visible(obj) → bool`, `setVisible(obj, bool)` | उसे दिखाता या छिपाता है। छिपे हुए ऑब्जेक्ट को `actualizar` मिलना बंद हो जाता है। |
| `setTinte(obj, r, g, b [, a])` | उसका रंग बदलता है (0 से 1 तक की वैल्यू)। |
