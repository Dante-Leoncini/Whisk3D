# 2D Editor

Per costruire interfacce di gioco, HUD e giochi 2D: testi, immagini, rettangoli, contenitori, slice 9, pulsanti e video.

| Funzione | Descrizione | Scorciatoia |
|---|---|---|
| Add | Text, Image, Rectangle, Container, Slice 9, Button, Expand, Video; Import w3dui. | Menu Add |
| Select | Il clic sceglie (trascinando si sposta); <kbd>Shift</kbd>+clic aggiunge; un clic nel vuoto deseleziona. | Clic; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Move / Rotate / Scale | <kbd>X</kbd> / <kbd>Y</kbd> bloccano l'asse; si può digitare il valore. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Ridimensionare | Le maniglie dell'elemento attivo. | Trascinare |
| Duplicate / Delete | Copia spostata e agganciata al puntatore / elimina con conferma. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Set Parent / Clear Parent | La selezione diventa figlia dell'elemento attivo, o torna a dipendere dalla UI. | Menu Object |
| Cursore 2D | Si posiziona con <kbd>Shift</kbd>+clic nel vuoto. | <kbd>Shift</kbd>+clic |
| Game View | La tela si vede esattamente come sul dispositivo, senza guide. | <kbd>Num0</kbd> (<kbd>Esc</kbd> esce) |
| Frame Selected / Zoom 1:1…4:1 | Inquadra la selezione; zoom esatto pixel per pixel. | <kbd>Num.</kbd> / menu View |
