# Armature

## Armature Edit Mode

| Funzione | Descrizione | Scorciatoia |
|---|---|---|
| Select | Sceglie un'estremità dell'osso o l'osso intero; trascinando lo si sposta subito. | Clic; <kbd>Shift</kbd> aggiunge |
| All / None | Seleziona o deseleziona tutte le ossa. | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extrude Bone | Crea un nuovo osso da ogni estremità selezionata. | <kbd>E</kbd> |
| Move / Rotate / Scale | Con assi e piani come sempre. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplicate | Copia le ossa e le lascia agganciate al puntatore. | <kbd>Shift+D</kbd> |
| Delete | Elimina le ossa (i loro figli passano al nonno). | <kbd>X</kbd> o <kbd>Delete</kbd> |
| Set Parent | Keep Offset o Connected. | <kbd>Ctrl+P</kbd> |
| Disconnect / Clear Parent | Stacca l'osso dal suo genitore. | <kbd>Alt+P</kbd> |

## Pose Mode

Solo per le armature. Serve per mettere in posa e animare.

| Funzione | Descrizione | Scorciatoia |
|---|---|---|
| Selezionare un osso | Sceglie un osso. | Clic; <kbd>Shift</kbd> aggiunge |
| Move / Rotate / Scale | Mette in posa le ossa selezionate. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Clear Location / Rotation / Scale | Riporta l'osso alla sua posa di riposo in quel canale. | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Insert Keyframe | Salva la posa nel frame attuale. | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
