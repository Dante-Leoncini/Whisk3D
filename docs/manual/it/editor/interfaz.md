# L'interfaccia

La finestra è divisa in **viewport** (pannelli). Ognuno può essere di un tipo: 3D Viewport, Outliner, Properties, UV Editor, Timeline, 2D Editor, Console o Script Editor (IDE).

| Funzione | Descrizione | Come si usa |
|---|---|---|
| Viewport attivo | Il viewport che riceve la tastiera. È evidenziato da un bordo verde e segue il puntatore: i tasti vanno al pannello che si trova sotto il mouse. | Spostare il mouse sopra. Su touch, toccarlo. |
| Cambiare il tipo di viewport | Trasforma il pannello in un altro tipo di editor. | Pulsante nell'angolo sinistro della sua barra superiore. |
| Split in Columns / Rows | Divide il viewport in due. | Pulsante dell'angolo → Split in Columns / Split in Rows. |
| Maximize / Minimize | Ingrandisce il viewport a tutta la finestra e lo riporta al suo posto. | Pulsante dell'angolo → Maximize. |
| Ridimensionare | Cambia la dimensione dei pannelli. | Trascinare il bordo tra due viewport (o l'angolo). |
| Barra superiore | I menu del viewport. Se non ci sta, scorre. | Rotella del mouse o trascinare con il dito. |
| Barra dei menu da tastiera | Apre la barra dei menu del viewport attivo per percorrerla con le frecce. | <kbd>M</kbd> (in Edit Mode, <kbd>M</kbd> è Merge). |
| Undo / Redo | Annulla o ripristina l'ultima azione. | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> o <kbd>Ctrl+Shift+Z</kbd>; frecce della barra inferiore. |
| Save project | Salva il .w3d aperto (se è nuovo, chiede un nome). | <kbd>Ctrl+S</kbd>, o Properties → scheda File/Render → riquadro File (vedi [Il progetto](proyecto.md)). |
| Fullscreen | Entra ed esce dalla modalità a schermo intero. | <kbd>F11</kbd>. Su Android è automatico se il telefono non ha il notch. |
| Play / Pause | Riproduce l'animazione (o il gioco) da qualsiasi pannello. | <kbd>Space</kbd> o il pulsante Play della timeline. |

**Su Android**: in verticale il layout è 3D Viewport sopra e Properties sotto; in orizzontale si aggiunge la timeline. Quando si apre la tastiera sullo schermo (per esempio nell'editor di script), il viewport attivo si massimizza nella parte visibile e torna al suo posto quando la tastiera si chiude.
