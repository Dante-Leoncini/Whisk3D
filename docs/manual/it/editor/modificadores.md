# Modificatori

Si aggiungono in Properties (riquadro Modifiers → Add) e cambiano la mesh senza distruggerla: si possono spegnere, riordinare o applicare (rendere definitivi) quando si vuole.

| Modificatore | Descrizione |
|---|---|
| Mirror | Riflette la mesh in X, Y e/o Z (o rispetto a un altro oggetto). Può saldare il centro ed evitare che si compenetri. |
| Array | Crea copie in fila: quantità, offset relativo (in base alla dimensione), offset costante (in metri) e facoltativamente in base a un altro oggetto (cumulativo: spirali, scale). Può saldare le copie. |
| Subdivision Surface | Ammorbidisce la mesh suddividendola (livelli per la vista e per il render). |
| Boolean | Intersezione, unione o differenza con un altro oggetto. |
| Screw | Fa ruotare un profilo attorno a un asse (viti, vasi, molle). |
| Armature | Deforma la mesh con un'armatura. |
| Culling | Ottimizzazione: non disegna le parti che non si vedono dalla camera. |
