# Scene e cinematiche

| Funzione | Cosa fa |
|---|---|
| `cambiarEscena(nombre [, reiniciar])` | Passa a un'altra scena (menu, livello 2…) alla fine del fotogramma. |
| `reproducirEscena(nombre [, "funcion"])` | Riproduce una scena 3D come cinematica con il gioco in pausa; al termine chiama quella funzione. |
| `pararEscena3D()`, `escenaReproduciendo()` | Interrompe la cinematica / dice quale si sta guardando. |
| `dibujar3D([on])` | Spegne o accende tutto il 3D (per esempio, dietro un menu opaco). |
