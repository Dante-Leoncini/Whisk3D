# Messaggi e debug

| Funzione | Cosa fa |
|---|---|
| `print(...)` | Scrive nel registro (log) del motore, non sullo schermo. |
| `info(msg)`, `aviso(msg)`, `error(msg)` | Messaggi di informazione, avviso o errore nel registro. `error` **non** interrompe lo script. |
| `depurar(msg)`, `esDebug()` | Messaggi solo nelle versioni di debug. |
| `logCantidad()`, `logLinea(i)` | Leggere il registro dal gioco (una console propria). |
