# Particelle, nebbia e visibilità

| Funzione | Cosa fa |
|---|---|
| `emitir(obj [, n])`, `setEmitiendo(obj, bool)` | Una raffica di particelle, o accendere/spegnere un emettitore. |
| `niebla(obj)`, `setNiebla(obj, densidad [, r, g, b, inicio, fin])` | Leggere e cambiare la nebbia. |
| `setSector`, `visCelda`, `setVisAncla`, `setVisCurvaT`, `setLote` | Controllo avanzato di quali parti del livello vengono disegnate. |
