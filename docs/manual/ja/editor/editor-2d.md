# 2D Editor

ゲームのインターフェース、HUD、2Dゲームを作るためのエディターです：テキスト、画像、矩形、コンテナ、Slice 9、ボタン、動画。

| 機能 | 説明 | ショートカット |
|---|---|---|
| Add | Text、Image、Rectangle、Container、Slice 9、Button、Expand、Video。Import w3dui。 | Addメニュー |
| Select | クリックで選択します（ドラッグで移動）。<kbd>Shift</kbd>+クリックで追加、何もない所をクリックすると選択を解除します。 | クリック。<kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Move / Rotate / Scale | <kbd>X</kbd> / <kbd>Y</kbd>で軸を固定します。値を入力することもできます。 | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| サイズ変更 | アクティブな要素のハンドルを使います。 | ドラッグ |
| Duplicate / Delete | ずらしたコピーを作ってつかんだ状態にします / 確認のうえ削除します。 | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Set Parent / Clear Parent | 選択したものをアクティブな要素の子にする、またはUIの直下に戻します。 | Objectメニュー |
| 2D Cursor | 何もない所を<kbd>Shift</kbd>+クリックして配置します。 | <kbd>Shift</kbd>+クリック |
| Game View | キャンバスがガイドなしで、デバイス上とまったく同じように表示されます。 | <kbd>Num0</kbd>（<kbd>Esc</kbd>で終了） |
| Frame Selected / Zoom 1:1…4:1 | 選択したものに表示を合わせます。ピクセル単位の正確なズームです。 | <kbd>Num.</kbd> / Viewメニュー |
