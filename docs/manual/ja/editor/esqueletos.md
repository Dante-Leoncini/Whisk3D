# アーマチュア

## Edit Mode（アーマチュア）

| 機能 | 説明 | ショートカット |
|---|---|---|
| Select | ボーンの先端の1つ、またはボーン全体を選択します。ドラッグするとそのまま移動します。 | クリック。<kbd>Shift</kbd>で追加 |
| All / None | すべてのボーンを選択、または選択解除します。 | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extrude Bone | 選択した各先端から新しいボーンを作成します。 | <kbd>E</kbd> |
| Move / Rotate / Scale | いつもどおり軸と平面を使えます。 | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplicate | ボーンをコピーして、つかんだ状態にします。 | <kbd>Shift+D</kbd> |
| Delete | ボーンを削除します（その子は祖父母のボーンに付け替えられます）。 | <kbd>X</kbd>または<kbd>Delete</kbd> |
| Set Parent | オフセットを保持、または接続。 | <kbd>Ctrl+P</kbd> |
| Disconnect / Clear Parent | ボーンを親から切り離します。 | <kbd>Alt+P</kbd> |

## Pose Mode

アーマチュア専用です。ポーズ付けとアニメーションに使います。

| 機能 | 説明 | ショートカット |
|---|---|---|
| ボーンの選択 | ボーンを選択します。 | クリック。<kbd>Shift</kbd>で追加 |
| Move / Rotate / Scale | 選択したボーンにポーズを付けます。 | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Clear Location / Rotation / Scale | そのチャンネルについて、ボーンを静止ポーズに戻します。 | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Insert Keyframe | 現在のフレームにポーズを保存します。 | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
