# モディファイアー

Properties（Modifiersカード → Add）で追加します。メッシュを壊さずに変形するので、いつでもオフにしたり、並べ替えたり、適用（ベイク）したりできます。

| モディファイアー | 説明 |
|---|---|
| Mirror | メッシュをX、Y、Zの1つ以上の軸で鏡映します（別のオブジェクトを基準にすることもできます）。中央を結合したり、反対側にはみ出さないようにしたりできます。 |
| Array | コピーを列状に並べます：個数、相対オフセット（サイズに応じた量）、固定オフセット（メートル単位）、必要に応じて別のオブジェクトを基準にしたオフセット（累積するので、らせんや階段が作れます）。コピー同士を結合することもできます。 |
| Subdivision Surface | メッシュを細分化して滑らかにします（ビュー用とレンダリング用のレベル）。 |
| Boolean | 別のオブジェクトとの交差、結合、差分。 |
| Screw | 断面を軸のまわりに回転させます（ネジ、花瓶、バネ）。 |
| Armature | アーマチュアでメッシュを変形します。 |
| Culling | 最適化：カメラから見えない部分を描画しません。 |
