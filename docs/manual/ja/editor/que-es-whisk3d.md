# Whisk3Dとは

Whisk3Dは、ゼロから作られた3Dエディター兼ゲームエンジンです。モデリング、ペイント、アニメーション、2Dインターフェースの作成、Luaによるゲームのプログラミングができます。**PC**（Linux、Windows）、**Android**、**ブラウザー**（Web）、**Nokia N95**（Symbian）で動作します。

作業内容はすべて`.w3d`プロジェクトファイルに保存されます。その中にはシーンだけでなく、リソースも入っています：テクスチャ（`texturas/`）、スクリプト（`scripts/`）、サウンド、シーン、プレハブ。リソースは.w3dの**中**に置くことも、ディスク上の個別のファイルとして**外**に置くこともできます。「Save inside the .w3d」と「Save outside the .w3d」のメニューで、どちらか一方へ移動できます。

> [!NOTE]
> このマニュアルでは、Whisk3Dが現在できることを説明しています。機能の名前は、エディターに英語で表示されるものです（エディターはまだ日本語に対応していません）。記載しているキーは初期設定のもので、[キーボードショートカット](atajos.md)で変更できます。
