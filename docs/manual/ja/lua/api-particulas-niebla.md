# パーティクル、フォグ、可視性

| 関数 | 説明 |
|---|---|
| `emitir(obj [, n])`、`setEmitiendo(obj, bool)` | パーティクルを一度に放出する、またはエミッターをオン・オフします。 |
| `niebla(obj)`、`setNiebla(obj, densidad [, r, g, b, inicio, fin])` | フォグの読み取りと変更。 |
| `setSector`、`visCelda`、`setVisAncla`、`setVisCurvaT`、`setLote` | レベルのどの部分を描画するかの高度な制御。 |
