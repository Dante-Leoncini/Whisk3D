# 軸、単位、オブジェクト

- **3D：** スクリプトでは**Y軸が上**を向きます。PropertiesパネルではZが上として表示されるため、パネルの「Z」フィールドがスクリプトの`y`にあたります。位置、回転、スケールは、オブジェクトの親に対する相対値です。回転は**度**で指定します。
- **2D（画面とUI）：** キャンバスのピクセル単位で、(0, 0)は**中央**です。+xは右、+yは**下**です。
- **オブジェクト：** オブジェクトを検索したり返したりする関数（`yo`、`buscar`、`objeto`…）が返す値には、フィールドもメソッドもありません。ほかの関数に渡して使います。2つのオブジェクトは`==`で比較できます。破棄されたオブジェクトは`nil`のようにふるまいます。
- **エラー耐性：** ほとんどの関数は、`nil`や種類の違うオブジェクトを渡しても壊れません。読み取る関数は0、`""`、`false`を返し、書き込む関数は何もしません。
- **インデックス：** Luaと同じく、ほとんどのものは1から始まります（頂点、指、レイヤー、ルーチンのステップ）。例外はルーチンのメモリ（`memoria`）で、0から255までです。
