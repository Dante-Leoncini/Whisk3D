# Luaとは何か、Whisk3Dでの用途

Luaは、小さく、高速で、覚えやすいプログラミング言語です。Whisk3Dには**Lua 5.4**が組み込まれていて、ゲームの*ロジック*に使われます：キーでキャラクターを動かす、得点を数える、メニューを開く、何かがぶつかったときに音を鳴らす、などです。

スクリプトはWhisk3Dの**Script Editor**（または任意のテキストエディター）で書き、`.lua`ファイルとして保存します。通常は`.w3d`プロジェクトの中（その`scripts/`フォルダー）に置きます。スクリプトが動くのはゲームの実行中だけです：Timelineを**Game**モードにして**Play**したとき、またはビルドしたゲームの中です。
