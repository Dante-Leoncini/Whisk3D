# Editor 2D

Para montar interfaces de jogo, HUD e jogos 2D: textos, imagens, retângulos, contêineres, slice 9, botões e vídeos.

| Função | Descrição | Atalho |
|---|---|---|
| Adicionar | Texto, imagem, retângulo, contêiner, slice 9, botão, expandir, vídeo; Importar w3dui. | Menu Adicionar |
| Selecionar | O clique escolhe (arrastar move); <kbd>Shift</kbd>+clique adiciona; clique no vazio desseleciona. | Clique; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Mover / Rotacionar / Escalar | <kbd>X</kbd> / <kbd>Y</kbd> travam o eixo; dá para digitar o valor. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Redimensionar | Os pontos de controle do elemento ativo. | Arrastar |
| Duplicar / Excluir | Cópia deslocada e presa ao ponteiro / exclui com confirmação. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Parentear / Desparentear | A seleção passa a ser filha do ativo, ou volta a pendurar-se na UI. | Menu Objeto |
| Cursor 2D | É posicionado com <kbd>Shift</kbd>+clique no vazio. | <kbd>Shift</kbd>+clique |
| Vista de jogo | O canvas aparece exatamente como no dispositivo, sem guias. | <kbd>Num0</kbd> (<kbd>Esc</kbd> sai) |
| Enquadrar / Zoom 1:1…4:1 | Enquadra a seleção; zoom exato pixel a pixel. | <kbd>Num.</kbd> / menu Vista |
