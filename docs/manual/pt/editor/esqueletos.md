# Armações

## Modo Edição de armação

| Função | Descrição | Atalho |
|---|---|---|
| Selecionar | Escolhe uma ponta do osso ou o osso inteiro; arrastar o move na hora. | Clique; <kbd>Shift</kbd> adiciona |
| Tudo / Nenhum | Seleciona ou desseleciona todos os ossos. | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extrudar osso | Cria um osso novo a partir de cada ponta selecionada. | <kbd>E</kbd> |
| Mover / Rotacionar / Escalar | Com eixos e planos, como sempre. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplicar | Copia os ossos e os deixa presos ao ponteiro. | <kbd>Shift+D</kbd> |
| Excluir | Exclui os ossos (seus filhos passam para o avô). | <kbd>X</kbd> ou <kbd>Delete</kbd> |
| Parentear | Manter deslocamento ou conectado. | <kbd>Ctrl+P</kbd> |
| Desconectar / Desparentear | Solta o osso do seu pai. | <kbd>Alt+P</kbd> |

## Modo Pose

Só para armações. Serve para posar e animar.

| Função | Descrição | Atalho |
|---|---|---|
| Selecionar osso | Escolhe um osso. | Clique; <kbd>Shift</kbd> adiciona |
| Mover / Rotacionar / Escalar | Posa os ossos selecionados. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Limpar posição / rotação / escala | Devolve o osso à sua pose de repouso nesse canal. | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Inserir keyframe | Salva a pose no quadro atual. | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
