# A interface

A janela se divide em **viewports** (painéis). Cada uma pode ser de um tipo: Viewport 3D, Outliner, Propriedades, Editor UV, Linha do Tempo, Editor 2D, Console ou Editor de scripts (IDE).

| Função | Descrição | Como usar |
|---|---|---|
| Viewport ativa | A viewport que recebe o teclado. É marcada com uma borda verde e segue o ponteiro: as teclas vão para o painel que está sob o mouse. | Passar o mouse por cima. Em telas touch, tocar nela. |
| Mudar o tipo de viewport | Transforma o painel em outro tipo de editor. | Botão do canto esquerdo da sua barra superior. |
| Dividir em colunas / linhas | Divide a viewport em duas. | Botão do canto → Dividir em colunas / Dividir em linhas. |
| Maximizar / Minimizar | Amplia a viewport para a janela inteira e a devolve ao seu lugar. | Botão do canto → Maximizar. |
| Redimensionar | Muda o tamanho dos painéis. | Arrastar a borda entre duas viewports (ou o canto). |
| Barra superior | Os menus da viewport. Se não couber, ela rola. | Roda do mouse ou arrastar com o dedo. |
| Barra de menus pelo teclado | Abre a barra de menus da viewport ativa para percorrê-la com as setas. | <kbd>M</kbd> (no Modo Edição, <kbd>M</kbd> é Mesclar). |
| Desfazer / Refazer | Volta para trás ou para frente a última ação. | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> ou <kbd>Ctrl+Shift+Z</kbd>; setas da barra inferior. |
| Salvar projeto | Salva o .w3d aberto (se for novo, pede um nome). | <kbd>Ctrl+S</kbd>, ou Propriedades → aba Arquivo/Render → cartão Arquivo (veja [O projeto](proyecto.md)). |
| Tela cheia | Entra e sai da tela cheia. | <kbd>F11</kbd>. No Android é automática se o celular não tiver notch. |
| Reproduzir / Pausa | Reproduz a animação (ou o jogo) a partir de qualquer painel. | <kbd>Espaço</kbd> ou o botão Play da Linha do Tempo. |

**No Android**: na vertical, o layout é Viewport 3D em cima e Propriedades embaixo; na horizontal, a Linha do Tempo é adicionada. Quando o teclado na tela se abre (por exemplo, no editor de scripts), a viewport ativa é maximizada na parte visível e volta ao seu lugar quando ele é fechado.
