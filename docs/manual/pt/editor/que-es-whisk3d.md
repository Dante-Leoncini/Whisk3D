# O que é o Whisk3D

O Whisk3D é um editor 3D e motor de jogos feito do zero. Com ele você modela, pinta, anima, monta interfaces 2D e programa jogos em Lua. Funciona no **PC** (Linux, Windows), no **Android**, no **navegador** (Web) e no **Nokia N95** (Symbian).

Todo o trabalho é salvo em um arquivo de projeto `.w3d`. Dentro dele vão a cena e também os recursos: texturas (`texturas/`), scripts (`scripts/`), sons, cenas, prefabs. Um recurso pode ficar **dentro** do .w3d ou **fora**, como um arquivo solto no disco; os menus "Salvar no w3d" e "Salvar fora do w3d" o movem de um lado para o outro.

> [!NOTE]
> Este manual descreve o que o Whisk3D sabe fazer hoje. Os nomes das funções são os que aparecem no editor em português. As teclas indicadas são as padrão: dá para mudá-las em [Atalhos de teclado](atajos.md).
