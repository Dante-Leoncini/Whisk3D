# Cenas e cinemáticas

| Função | O que faz |
|---|---|
| `cambiarEscena(nombre [, reiniciar])` | Passa para outra cena (menu, nível 2…) no fim do quadro. |
| `reproducirEscena(nombre [, "funcion"])` | Reproduz uma cena 3D como cinemática com o jogo em pausa; ao terminar, chama essa função. |
| `pararEscena3D()`, `escenaReproduciendo()` | Interrompe a cinemática / diz qual está sendo vista. |
| `dibujar3D([on])` | Desliga ou liga todo o 3D (por exemplo, atrás de um menu opaco). |
