# Mensagens e depuração

| Função | O que faz |
|---|---|
| `print(...)` | Escreve no registro (log) do motor, não na tela. |
| `info(msg)`, `aviso(msg)`, `error(msg)` | Mensagens de informação, aviso ou erro no registro. `error` **não** interrompe o script. |
| `depurar(msg)`, `esDebug()` | Mensagens só em versões de depuração. |
| `logCantidad()`, `logLinea(i)` | Ler o registro a partir do jogo (um console próprio). |
