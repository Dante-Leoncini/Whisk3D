# Partículas, névoa e visibilidade

| Função | O que faz |
|---|---|
| `emitir(obj [, n])`, `setEmitiendo(obj, bool)` | Uma rajada de partículas, ou ligar/desligar um emissor. |
| `niebla(obj)`, `setNiebla(obj, densidad [, r, g, b, inicio, fin])` | Ler e mudar a névoa. |
| `setSector`, `visCelda`, `setVisAncla`, `setVisCurvaT`, `setLote` | Controle avançado de quais partes do nível são desenhadas. |
