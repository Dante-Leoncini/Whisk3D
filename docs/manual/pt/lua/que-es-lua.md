# O que é Lua e para que serve no Whisk3D

Lua é uma linguagem de programação pequena, rápida e fácil de aprender. O Whisk3D traz embutido o **Lua 5.4** e o usa para a *lógica* dos jogos: mover um personagem com as teclas, contar pontos, abrir um menu, tocar um som quando algo colide.

Os scripts são escritos no **editor de scripts** do Whisk3D (ou em qualquer editor de texto) e salvos como arquivos `.lua`, normalmente dentro do projeto `.w3d` (na sua pasta `scripts/`). Eles só rodam quando o jogo está em andamento: com a timeline no modo **Jogo** e em **Play**, ou em um jogo compilado.
