# 2D Editor

Для создания игровых интерфейсов, HUD и 2D-игр: тексты, изображения, прямоугольники, контейнеры, slice 9, кнопки и видео.

| Функция | Описание | Сочетание |
|---|---|---|
| Add | Text, Image, Rectangle, Container, Slice 9, Button, Expand, Video; Import w3dui. | Меню Add |
| Select | Клик выбирает (перетаскивание перемещает); <kbd>Shift</kbd>+клик добавляет; клик по пустому месту снимает выделение. | Клик; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Move / Rotate / Scale | <kbd>X</kbd> / <kbd>Y</kbd> фиксируют ось; значение можно ввести с клавиатуры. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Изменение размера | Точки захвата активного элемента. | Перетаскивание |
| Duplicate / Delete | Копия со смещением, сразу захваченная / удаление с подтверждением. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Set Parent / Clear Parent | Выделение становится потомком активного элемента или снова подчиняется UI. | Меню Object |
| 2D Cursor | Ставится через <kbd>Shift</kbd>+клик по пустому месту. | <kbd>Shift</kbd>+клик |
| Game View | Холст выглядит точно так же, как на устройстве, без направляющих. | <kbd>Num0</kbd> (<kbd>Esc</kbd> — выход) |
| Frame Selected / Zoom 1:1…4:1 | Кадрирует выделение; точный зум пиксель в пиксель. | <kbd>Num.</kbd> / меню View |
