# Скелеты

## Edit Mode скелета

| Функция | Описание | Сочетание |
|---|---|---|
| Select | Выбирает конец кости или всю кость; перетаскивание сразу её перемещает. | Клик; <kbd>Shift</kbd> добавляет |
| All / None | Выделяет все кости или снимает с них выделение. | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extrude Bone | Создаёт новую кость из каждого выделенного конца. | <kbd>E</kbd> |
| Move / Rotate / Scale | С осями и плоскостями, как обычно. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplicate | Копирует кости и оставляет их захваченными. | <kbd>Shift+D</kbd> |
| Delete | Удаляет кости (их потомки переходят к «деду»). | <kbd>X</kbd> или <kbd>Delete</kbd> |
| Set Parent | Keep Offset или Connected. | <kbd>Ctrl+P</kbd> |
| Disconnect / Clear Parent | Отсоединяет кость от её родителя. | <kbd>Alt+P</kbd> |

## Pose Mode

Только для скелетов. Нужен, чтобы ставить позы и анимировать.

| Функция | Описание | Сочетание |
|---|---|---|
| Выбор кости | Выбирает кость. | Клик; <kbd>Shift</kbd> добавляет |
| Move / Rotate / Scale | Ставит в позу выделенные кости. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Clear Location / Rotation / Scale | Возвращает кость в позу покоя по этому каналу. | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Insert Keyframe | Сохраняет позу в текущем кадре. | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
