# Интерфейс

Окно делится на **вьюпорты** (панели). Каждый из них может быть одного из типов: 3D Viewport, Outliner, Properties, UV Editor, Timeline, 2D Editor, Console или Script Editor (IDE).

| Функция | Описание | Как использовать |
|---|---|---|
| Активный вьюпорт | Вьюпорт, который получает ввод с клавиатуры. Он выделен зелёной рамкой и следует за указателем: клавиши идут в панель под мышью. | Навести на него мышь. На сенсорном экране — коснуться его. |
| Сменить тип вьюпорта | Превращает панель в редактор другого типа. | Кнопка в левом углу его верхней панели. |
| Split in Columns / Rows | Делит вьюпорт на два. | Кнопка в углу → Split in Columns / Split in Rows. |
| Maximize / Minimize | Разворачивает вьюпорт на всё окно и возвращает его на место. | Кнопка в углу → Maximize. |
| Изменение размера | Меняет размер панелей. | Перетащить границу между двумя вьюпортами (или угол). |
| Верхняя панель | Меню вьюпорта. Если она не помещается, её можно прокручивать. | Колесо мыши или перетаскивание пальцем. |
| Строка меню с клавиатуры | Открывает строку меню активного вьюпорта, чтобы перемещаться по ней стрелками. | <kbd>M</kbd> (в Edit Mode <kbd>M</kbd> — это Merge). |
| Undo / Redo | Отменяет или возвращает последнее действие. | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> или <kbd>Ctrl+Shift+Z</kbd>; стрелки на нижней панели. |
| Save project | Сохраняет открытый .w3d (если он новый, спрашивает имя). | <kbd>Ctrl+S</kbd> или Properties → вкладка File/Render → карточка File (см. [Проект](proyecto.md)). |
| Fullscreen | Включает и выключает полноэкранный режим. | <kbd>F11</kbd>. На Android включается автоматически, если у телефона нет выреза (notch). |
| Play / Pause | Воспроизводит анимацию (или игру) из любой панели. | <kbd>Space</kbd> или кнопка Play на Timeline. |

**На Android**: в вертикальной ориентации сверху 3D Viewport, а снизу Properties; в горизонтальной добавляется Timeline. Когда открывается экранная клавиатура (например, в редакторе скриптов), активный вьюпорт разворачивается на видимую часть экрана и возвращается на место, когда клавиатура закрывается.
