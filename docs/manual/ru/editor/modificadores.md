# Модификаторы

Добавляются в Properties (карточка Modifiers → Add) и изменяют меш, не разрушая его: их можно в любой момент выключить, переупорядочить или применить (запечь).

| Модификатор | Описание |
|---|---|
| Mirror | Отражает меш по X, Y и/или Z (или относительно другого объекта). Может сваривать центр и не давать половинам пересекаться. |
| Array | Создаёт копии в ряд: количество, относительное смещение (по размеру), постоянное смещение (в метрах) и, по желанию, смещение по другому объекту (накопительное: спирали, лестницы). Может сваривать копии. |
| Subdivision Surface | Сглаживает меш, подразделяя его (отдельные уровни для вида и для рендера). |
| Boolean | Intersect, Union или Difference с другим объектом. |
| Screw | Вращает профиль вокруг оси (винты, вазы, пружины). |
| Armature | Деформирует меш с помощью скелета. |
| Culling | Оптимизация: не рисует части, которые не видны из камеры. |
