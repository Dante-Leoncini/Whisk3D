# Edit Mode (меши)

Вход — клавишей <kbd>Tab</kbd> на меше. Работа идёт с **вершинами**, **рёбрами** или **гранями** в зависимости от кнопки на верхней панели.

## Выделение

| Функция | Описание | Сочетание |
|---|---|---|
| Select | Выбирает вершину, ребро или грань. | Клик; <kbd>Shift</kbd>+клик переключает |
| Select Linked | Весь связанный остров под указателем. | <kbd>L</kbd> |
| Loop Select | Кольцо рёбер или граней. | <kbd>Shift+Alt</kbd>+клик |
| Pick Shortest Path | Выделяет путь между активным элементом и тем, по которому кликнули. | <kbd>Ctrl</kbd>+клик |
| Shortest Path (Fill Region) | Выделяет всю область между ними. | <kbd>Ctrl+Shift</kbd>+клик |
| All / None / Invert / Box Select | Как в Object Mode, но для элементов меша. | <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> / <kbd>B</kbd> |

## Моделирование

| Функция | Описание | Сочетание |
|---|---|---|
| Move / Rotate / Scale | Трансформирует выделенное. Если перемещение уже идёт, повторное нажатие <kbd>G</kbd> переключает на скольжение. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Shrink/Fatten | Сдвигает каждую вершину вдоль её нормали (раздувает или сдувает). | <kbd>Alt+S</kbd> |
| Extrude | Выдавливает новую геометрию из выделенного (грани выходят вдоль своей нормали). | <kbd>E</kbd> |
| Loop Cut and Slide | Разрезает кольцо рёбер. Колесо меняет количество разрезов; клик применяет, после чего разрез можно сдвинуть. | <kbd>Ctrl+R</kbd> |
| New Edge/Face from Vertices | Соединяет выделенные вершины ребром или гранью. | <kbd>F</kbd> |
| Connect Vertex Path | Разрезает по прямой между двумя вершинами. | <kbd>J</kbd> |
| Slide Vertices | Сдвигает вершины вдоль их рёбер. | <kbd>Shift+V</kbd> |
| Rip | Разрывает меш по выделению. | <kbd>V</kbd> |
| Duplicate | Копирует выделенное и оставляет его захваченным. | <kbd>Shift+D</kbd> |
| Separate | Переносит выделенные грани в новый объект. | <kbd>P</kbd> |
| Merge | Сливает вершины: At Center, At Cursor, Collapse или By Distance. | <kbd>M</kbd> |
| Auto Merge | По окончании перемещения сливает вершины, оказавшиеся ближе порогового значения. | Меню Mesh |
| Delete | Вершины, рёбра, грани или петли рёбер. | <kbd>X</kbd> или <kbd>Delete</kbd> |
| Recalculate Normals / Flip | Исправляет направление граней или разворачивает их. | <kbd>Shift+N</kbd> |
| Triangulate Faces | Разбивает на треугольники грани, у которых больше 3 сторон. | <kbd>Ctrl+T</kbd> |
| Shade Smooth / Shade Flat | Как освещается поверхность. | Меню Face |
| Mark / Clear Sharp | Рёбра, которые выглядят жёсткими, даже если меш сглажен. | Меню Edge |
| Mark / Clear Seam | Где меш разрезается при развёртке UV. | Меню Edge или UV |
| Context menu | Операции текущего подрежима (вершины, рёбра или грани) у указателя. | <kbd>W</kbd> или правый клик |
| Insert Keyframe | Сохраняет форму меша в текущем кадре (вершинная анимация). | <kbd>I</kbd> |

## Меню UV

| Функция | Описание | Сочетание |
|---|---|---|
| Unwrap | Angle Based, Conformal или Minimum Stretch: раскрывает меш по его швам. | <kbd>U</kbd> |
| Smart UV Project | Сама разрезает и разворачивает в зависимости от углов между гранями. | <kbd>U</kbd> |
| Lightmap Pack / Follow Active Quads | Острова уложены без перекрытий / UV выровнены по активной грани. | <kbd>U</kbd> |
| Cube, Cylinder, Sphere Projection, Project from View | Простые проекции. | <kbd>U</kbd> |
| Reset | Каждая грань занимает всё изображение. | <kbd>U</kbd> |

## Редактирование кривых (путей)

Клавишей <kbd>Tab</kbd> на кривой её узлы редактируются как меш из точек: <kbd>G</kbd> перемещает, <kbd>E</kbd> добавляет следующий узел, <kbd>X</kbd> удаляет.
