# Другие функции 3D Viewport

| Функция | Описание | Как использовать |
|---|---|---|
| Camera View | Вид через активную камеру с рамкой размера рендера. Внутри неё колесо или щипок дают зум для осмотра, не сдвигая камеру. | <kbd>Num0</kbd> |
| Local View | Изолирует выделенное (вместе с его родителями и потомками); повторное нажатие возвращает всё. | <kbd>/</kbd> |
| 3D Cursor | Точка, где появляются новые объекты; также служит опорной точкой. Ставится через меню Snap (<kbd>Shift+S</kbd>). | <kbd>Shift+S</kbd> |
| Ray Tracing | Реалистичный рендер с мягкими тенями, прозрачностью, отражениями (шероховатость и металличность материала) и картами нормалей. Включается в Properties → Render и отображается в Render Preview; изображение достраивается постепенно. | Properties → Render |
| Игровой режим | Когда анимация "Game" запущена через Play, клики и клавиши идут в игру. <kbd>Esc</kbd> ставит на паузу. | Кнопки Play / Stop на панели |
