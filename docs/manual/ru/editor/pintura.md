# Режимы рисования

> [!NOTE]
> Все три режима рисования — **только для 3D-мешей**: они не появляются для камер, источников света, скелетов, кривых и 2D-элементов. Во время рисования клик не меняет выделение; чтобы рисовать на другом объекте, выбери его в Outliner.

## Общее для всех трёх

| Функция | Описание | Как использовать |
|---|---|---|
| Рисование | Рисует только видимые лицевые грани (с X-Ray — также задние). Каждый мазок — отдельный шаг отмены. | Клик и перетаскивание |
| Radius | Размер кисти в пикселях. При его изменении в центре вида появляется круг реального размера. | Перетаскиваемый ползунок над нижней панелью |
| Value | Интенсивность кисти. | Перетаскиваемый ползунок |
| Falloff | Как сглаживается край кисти; можно нарисовать собственную кривую. | Кнопка спада |
| Вид (сенсорный экран) | Включено: палец перемещает вид. Выключено: палец рисует. | Кнопка в виде монитора |

## Weight Paint

Рисует, насколько кость влияет на каждую вершину (синий = никак, красный = полностью). Именно благодаря этому меш правильно деформируется вместе со скелетом.

| Функция | Описание |
|---|---|
| Режим кисти | Добавить (+), Вычесть (−) или Уравнять (=, ставит точное значение). |
| Группа вершин | Какая группа (кость) рисуется; можно добавлять группы. Если групп нет, первый мазок создаёт одну. |
| Метки | Показывает квадратик на каждой вершине; кисть действует только на них. |
| Только выделенное | Защищает невыделенное (оно затемнено). |

## Vertex Paint

Рисует цвета по вершинам **3D-меша** (не подходит для изображений и 2D-элементов: для этого есть Texture Paint). Это очень лёгкий режим, и именно его рекомендуется использовать для раскраски на N95.

| Функция | Описание |
|---|---|
| Color | Открывает выбор цвета (RGB, HSV, шестнадцатеричный код или индекс палитры). |
| Per-Vertex / Per-Corner | При Per-Vertex цвет общий для соседних граней; при Per-Corner у каждой грани может быть свой (жёсткие границы). |
| Color Layer | Выбор или создание цветовых слоёв. |
| Метки / Только выделенное | Так же, как в Weight Paint. |

## Texture Paint

Рисует прямо по 3D-объекту, а мазок попадает в его текстуру.

| Функция | Описание |
|---|---|
| Автоматическая текстура | Если у меша нет текстуры, она создаётся сама при первом мазке: собственный материал, автоматические UV и изображение 1024×1024 (256×256 на N95) цвета материала. |
| Color, Falloff, Radius, Value | Как в других режимах. |
| Save Texture | Рисунок хранится в памяти, пока его не сохранят. Дискета становится зелёной, если есть несохранённые изменения. Варианты: Save, Save As…, Save inside the .w3d и Save outside the .w3d… |
