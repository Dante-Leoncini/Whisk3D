# Проект (.w3d) и файлы

| Функция | Описание | Где |
|---|---|---|
| Open project | Открывает .w3d (также двойным кликом в системе). | Properties → File/Render → File |
| Save / Save As | Сохраняет в папку и под именем, указанными в карточке; Save As спрашивает другое. Если имя не задано, поле становится красным. | Карточка File, <kbd>Ctrl+S</kbd> |
| Save Version | Сохраняет и вдобавок оставляет пронумерованную копию (`proyecto_v03.w3d`). | Карточка File |
| Extract assets | Копирует всё содержимое в папку (копии не меняют проект). | Карточка File |
| Meshes as text | Сохраняет меши как читаемый текст вместо двоичного формата. | Карточка File |
| Импорт | OBJ, FBX, glTF, GLB и интерфейсы .w3dui. Импортированное копируется внутрь проекта (без дубликатов). | 3D Viewport → Add → Imports |
| Export | OBJ, glTF или GLB выделенного объекта (с модификаторами и трансформациями или без них). | Properties → Export |
| Несохранённые изменения | Отредактированное, но не сохранённое (скрипты, раскрашенные текстуры) помечается `*`. При закрытии или открытии другого проекта предупреждение перечисляет, что будет потеряно. | Автоматически |
| Ресурс внутри или снаружи | Внешний ресурс не копируется: сохраняется его путь, а если файл пропал, выводится предупреждение. | Карточка Resource; "Save inside / outside the .w3d" в IDE и UV Editor |

Сохранение никогда не оставляет файл записанным наполовину: сначала пишется временная копия, а затем она переименовывается.
