# Клавиатура, геймпад, сенсорный экран и мышь

| Функция | Что делает |
|---|---|
| `tecla(nombre) → bool` | Клавиша нажата (пока ты её удерживаешь). |
| `teclaApretada(nombre) → bool` | Клавиша нажата именно в этом кадре (один раз за нажатие). |
| `boton(nombre)`, `botonApretado(nombre)` | То же самое для кнопки геймпада. |
| `stick(["izq"\|"der"]) → x, y` | Стик геймпада, от -1 до 1 (вверх — это -1). |
| `gatillo(["izq"\|"der"]) → 0..1` | Аналоговый курок. |
| `controles() → n`, `control([n]) → nombre, tipo` | Сколько геймпадов подключено и какого они типа (`"xbox"`, `"playstation"`, `"nintendo"`, `"generico"`). |
| `toque() → x, y, tocando` | Палец (или клик мыши) на экране. |
| `dedo([n]) → x, y, activo` | Мультитач: палец номер n (от 1 до 4). |
| `apretado(obj) → bool` | Этого 2D-элемента коснулись или кликнули по нему в этом кадре (кнопки). |
| `raton() → x, y, dentro` | Где находится мышь. |
| `capturarRaton(bool)`, `ratonRel() → dx, dy`, `ratonCapturado()` | Захват мыши, чтобы осматриваться мышью (игры от первого лица, только ПК). |
