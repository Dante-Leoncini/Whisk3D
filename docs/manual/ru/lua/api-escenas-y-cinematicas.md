# Сцены и кат-сцены

| Функция | Что делает |
|---|---|
| `cambiarEscena(nombre [, reiniciar])` | Переходит к другой сцене (меню, уровень 2…) в конце кадра. |
| `reproducirEscena(nombre [, "funcion"])` | Воспроизводит 3D-сцену как кат-сцену, поставив игру на паузу; по окончании вызывает указанную функцию. |
| `pararEscena3D()`, `escenaReproduciendo()` | Прерывает кат-сцену / сообщает, какая сейчас воспроизводится. |
| `dibujar3D([on])` | Выключает или включает весь 3D (например, за непрозрачным меню). |
