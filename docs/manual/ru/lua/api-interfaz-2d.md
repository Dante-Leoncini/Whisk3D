# 2D-интерфейс и экран

| Функция | Что делает |
|---|---|
| `pantalla() → ancho, alto` | Размер холста. |
| `areaSegura() → x, y, w, h` | Часть экрана без выреза (не использовать в `inicio`). |
| `escala() → f` | Без аргументов: коэффициент для подгонки размеров под экран (меньшая сторона / 480). |
| `posPx(obj) → x, y`, `setPosPx(obj, x, y)` | Положение 2D-элемента (`nil` оставляет эту ось без изменений). |
| `tamPx(obj) → w, h`, `setTamPx(obj, w, h)` | Размер 2D-элемента. |
| `cajaUI(obj) → x, y, w, h` | Прямоугольник, который элемент реально занимает (x, y = центр). |
| `setTexto(obj, valor)`, `setTam(texto, px)` | Меняет текст у текста или кнопки, а также размер шрифта. |
| `setTextura(img, "ruta.png")`, `setUVRect`, `setFlipbook` | Меняет изображение, вырезает его часть или анимирует лист кадров. |
| `setOpacidad(obj, 0..1)`, `fundir(obj, objetivo, paso)` | Прозрачность и плавные переходы. |
| `setRot2D(obj, grados)` | Поворачивает 2D-элемент. |
| `chocan(a, b) → bool` | Перекрываются ли два 2D-элемента на экране. |
| `limitar(obj, area [, eje])`, `dentro(area, x [, y])` | Удерживать элемент внутри другого или проверить, находится ли точка внутри. |
| `salir()` | Закрывает игру (в редакторе ничего не делает). |
