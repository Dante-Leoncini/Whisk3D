# Сообщения и отладка

| Функция | Что делает |
|---|---|
| `print(...)` | Пишет в журнал (лог) движка, а не на экран. |
| `info(msg)`, `aviso(msg)`, `error(msg)` | Информационные сообщения, предупреждения или ошибки в журнале. `error` **не** прерывает скрипт. |
| `depurar(msg)`, `esDebug()` | Сообщения только в отладочных сборках. |
| `logCantidad()`, `logLinea(i)` | Читать журнал из игры (собственная консоль). |
