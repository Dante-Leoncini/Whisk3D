# Частицы, туман и видимость

| Функция | Что делает |
|---|---|
| `emitir(obj [, n])`, `setEmitiendo(obj, bool)` | Выброс частиц или включение/выключение излучателя. |
| `niebla(obj)`, `setNiebla(obj, densidad [, r, g, b, inicio, fin])` | Чтение и изменение тумана. |
| `setSector`, `visCelda`, `setVisAncla`, `setVisCurvaT`, `setLote` | Расширенное управление тем, какие части уровня рисуются. |
