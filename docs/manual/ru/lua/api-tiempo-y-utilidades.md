# Время, случайные числа и утилиты

| Функция | Что делает |
|---|---|
| `azar() → 0..1`, `azar(min, max) → entero` | Случайные числа. |
| `relojMs() → ms` | Миллисекунды, чтобы измерить, сколько времени что-то занимает. |
| `perfilLua(cuadros [, etiqueta])` | Измеряет, какие части скрипта работают медленно (`perfilLua(0)` выключает замер). |
| `lineaCrear(nombre, puntos)`, `lineaPunto(id, s)` | Плавная замкнутая кривая, которую рассчитывает движок (маршруты). |

Функции "время с начала игры" нет: суммируй `dt` в переменной.
