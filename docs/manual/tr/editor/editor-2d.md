# 2D Editor

Oyun arayüzleri, HUD'lar ve 2D oyunlar kurmak için: metinler, görüntüler, dikdörtgenler, kapsayıcılar, slice 9, düğmeler ve videolar.

| İşlev | Açıklama | Kısayol |
|---|---|---|
| Add | Text, Image, Rectangle, Container, Slice 9, Button, Expand, Video; Import w3dui. | Add menüsü |
| Select | Tık seçer (sürüklemek taşır); <kbd>Shift</kbd>+tık ekler; boş alana tıklamak seçimi kaldırır. | Tık; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Move / Rotate / Scale | <kbd>X</kbd> / <kbd>Y</kbd> ekseni kilitler; değeri yazabilirsin. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Yeniden boyutlandırma | Etkin öğenin tutma noktaları. | Sürükleme |
| Duplicate / Delete | Kaydırılmış ve tutulmuş bir kopya / onay isteyerek siler. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Set Parent / Clear Parent | Seçim etkin öğenin çocuğu olur ya da yeniden doğrudan UI'a bağlanır. | Object menüsü |
| 2D Cursor | Boş alanda <kbd>Shift</kbd>+tık ile yerleştirilir. | <kbd>Shift</kbd>+tık |
| Game View | Tuval, kılavuz çizgileri olmadan tam olarak cihazdaki gibi görünür. | <kbd>Num0</kbd> (<kbd>Esc</kbd> ile çıkılır) |
| Frame Selected / Zoom 1:1…4:1 | Seçimi kadraja alır; piksel piksel tam yakınlaştırma. | <kbd>Num.</kbd> / View menüsü |
