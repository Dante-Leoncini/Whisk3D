# İskeletler

## Edit Mode (iskelet)

| İşlev | Açıklama | Kısayol |
|---|---|---|
| Select | Kemiğin bir ucunu ya da kemiğin tamamını seçer; sürüklemek onu anında taşır. | Tık; <kbd>Shift</kbd> ekler |
| All / None | Tüm kemikleri seçer ya da tüm kemiklerin seçimini kaldırır. | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extrude Bone | Seçili her uçtan yeni bir kemik oluşturur. | <kbd>E</kbd> |
| Move / Rotate / Scale | Her zamanki gibi eksenler ve düzlemlerle. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplicate | Kemikleri kopyalar ve tutulmuş hâlde bırakır. | <kbd>Shift+D</kbd> |
| Delete | Kemikleri siler (çocukları büyük ebeveyne geçer). | <kbd>X</kbd> ya da <kbd>Delete</kbd> |
| Set Parent | Keep Offset ya da Connected. | <kbd>Ctrl+P</kbd> |
| Disconnect / Clear Parent | Kemiği ebeveyninden ayırır. | <kbd>Alt+P</kbd> |

## Pose Mode

Yalnızca iskeletler için. Poz vermeye ve canlandırmaya yarar.

| İşlev | Açıklama | Kısayol |
|---|---|---|
| Select (kemik) | Bir kemik seçer. | Tık; <kbd>Shift</kbd> ekler |
| Move / Rotate / Scale | Seçili kemiklere poz verir. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Clear Location / Rotation / Scale | Kemiği o kanalda dinlenme pozuna döndürür. | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Insert Keyframe | Pozu geçerli karede kaydeder. | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
