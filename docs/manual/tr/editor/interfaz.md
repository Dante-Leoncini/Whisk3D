# Arayüz

Pencere **viewport**'lara (panellere) bölünür. Her biri şu türlerden biri olabilir: 3D Viewport, Outliner, Properties, UV Editor, Timeline, 2D Editor, Console veya Script Editor (IDE).

| İşlev | Açıklama | Nasıl kullanılır |
|---|---|---|
| Etkin viewport | Klavye girdisini alan viewport. Yeşil bir kenarlıkla işaretlenir ve işaretçiyi takip eder: tuşlar farenin altındaki panele gider. | Fareyi üzerine getir. Dokunmatik ekranda ona dokun. |
| Viewport türünü değiştirme | Paneli başka bir editör türüne dönüştürür. | Üst çubuğunun sol köşesindeki düğme. |
| Split in Columns / Rows | Viewport'u ikiye böler. | Köşe düğmesi → Split in Columns / Split in Rows. |
| Maximize / Minimize | Viewport'u tüm pencereyi kaplayacak şekilde büyütür ve yerine geri döndürür. | Köşe düğmesi → Maximize. |
| Yeniden boyutlandırma | Panellerin boyutunu değiştirir. | İki viewport arasındaki kenarı (ya da köşeyi) sürükle. |
| Üst çubuk | Viewport'un menüleri. Sığmazsa kaydırılır. | Fare tekerleği ya da parmakla sürükleme. |
| Klavyeyle menü çubuğu | Etkin viewport'un menü çubuğunu açar, ok tuşlarıyla gezebilirsin. | <kbd>M</kbd> (Edit Mode'da <kbd>M</kbd>, Merge işlevidir). |
| Undo / Redo | Son işlemi geri alır ya da yineler. | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> veya <kbd>Ctrl+Shift+Z</kbd>; alt çubuktaki oklar. |
| Save project | Açık .w3d'yi kaydeder (yeniyse ad ister). | <kbd>Ctrl+S</kbd> ya da Properties → File/Render sekmesi → File kartı ([Proje](proyecto.md) bölümüne bak). |
| Fullscreen | Tam ekrana girer ve çıkar. | <kbd>F11</kbd>. Android'de telefonda çentik yoksa otomatiktir. |
| Play / Pause | Animasyonu (ya da oyunu) herhangi bir panelden oynatır. | <kbd>Space</kbd> ya da Timeline'daki Play düğmesi. |

**Android'de**: dikey konumda düzen, üstte 3D Viewport ve altta Properties şeklindedir; yatay konumda buna Timeline da eklenir. Ekran klavyesi açıldığında (örneğin Script Editor'de), etkin viewport görünen alanda büyütülür ve klavye kapanınca yerine döner.
