# Sahneler ve ara sahneler

| Fonksiyon | Ne yapar |
|---|---|
| `cambiarEscena(nombre [, reiniciar])` | Karenin sonunda başka bir sahneye (menü, 2. seviye…) geçer. |
| `reproducirEscena(nombre [, "funcion"])` | Oyun duraklatılmışken bir 3D sahneyi ara sahne olarak oynatır; bitince o fonksiyonu çağırır. |
| `pararEscena3D()`, `escenaReproduciendo()` | Ara sahneyi keser / hangisinin oynatıldığını söyler. |
| `dibujar3D([on])` | Tüm 3D'yi kapatır ya da açar (örneğin opak bir menünün arkasında). |
