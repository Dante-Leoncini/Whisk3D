# 2D Editor

用于搭建游戏界面、HUD 和 2D 游戏：文本、图像、矩形、容器、slice 9、按钮和视频。

| 功能 | 说明 | 快捷键 |
|---|---|---|
| Add | Text、Image、Rectangle、Container、Slice 9、Button、Expand、Video；Import w3dui。 | Add 菜单 |
| Select | 单击选择（拖动可移动）；<kbd>Shift</kbd>+单击加选；在空白处单击取消选择。 | 单击；<kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Move / Rotate / Scale | <kbd>X</kbd> / <kbd>Y</kbd> 锁定轴；可以直接输入数值。 | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| 调整大小 | 活动元素的抓取点。 | 拖动 |
| Duplicate / Delete | 偏移并被抓取的副本 / 确认后删除。 | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Set Parent / Clear Parent | 所选元素成为活动元素的子级，或重新挂回 UI 之下。 | Object 菜单 |
| 2D Cursor | 在空白处 <kbd>Shift</kbd>+单击来放置。 | <kbd>Shift</kbd>+单击 |
| Game View | 画布的显示效果与设备上完全一致，没有参考线。 | <kbd>Num0</kbd>（<kbd>Esc</kbd> 退出） |
| Frame Selected / Zoom 1:1…4:1 | 让所选内容填满视图；逐像素的精确缩放。 | <kbd>Num.</kbd> / View 菜单 |
