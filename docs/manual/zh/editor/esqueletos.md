# 骨架

## 骨架的 Edit Mode

| 功能 | 说明 | 快捷键 |
|---|---|---|
| Select | 选择骨骼的一个端点或整根骨骼；拖动可以直接移动它。 | 单击；<kbd>Shift</kbd> 加选 |
| All / None | 选中或取消选中所有骨骼。 | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extrude Bone | 从每个选中的端点创建一根新骨骼。 | <kbd>E</kbd> |
| Move / Rotate / Scale | 和平常一样，可以使用轴和平面约束。 | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplicate | 复制骨骼，并保持抓取状态。 | <kbd>Shift+D</kbd> |
| Delete | 删除骨骼（它们的子骨骼会转到祖父骨骼下）。 | <kbd>X</kbd> 或 <kbd>Delete</kbd> |
| Set Parent | Keep Offset 或 Connected。 | <kbd>Ctrl+P</kbd> |
| Disconnect / Clear Parent | 把骨骼从它的父级上解开。 | <kbd>Alt+P</kbd> |

## Pose Mode

仅适用于骨架。用于摆姿势和制作动画。

| 功能 | 说明 | 快捷键 |
|---|---|---|
| 选择骨骼 | 选择一根骨骼。 | 单击；<kbd>Shift</kbd> 加选 |
| Move / Rotate / Scale | 为所选骨骼摆姿势。 | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Clear Location / Rotation / Scale | 让骨骼在该通道上回到静止姿势。 | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Insert Keyframe | 在当前帧保存姿势。 | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
