# 界面

窗口被划分为多个 **viewport**（面板）。每个面板可以是以下类型之一：3D Viewport、Outliner、Properties、UV Editor、Timeline、2D Editor、Console 或 Script Editor（IDE）。

| 功能 | 说明 | 使用方法 |
|---|---|---|
| 活动视口 | 接收键盘输入的视口。它带有绿色边框，并跟随鼠标指针：按键会发送到鼠标下方的面板。 | 把鼠标移到它上面。触屏上点一下即可。 |
| 更改视口类型 | 把该面板切换成另一种编辑器。 | 顶部栏左侧角落的按钮。 |
| Split in Columns / Rows | 把视口一分为二。 | 角落按钮 → Split in Columns / Split in Rows。 |
| Maximize / Minimize | 把视口放大到整个窗口，或让它回到原位。 | 角落按钮 → Maximize。 |
| 调整大小 | 改变各面板的大小。 | 拖动两个视口之间的边框（或角落）。 |
| 顶部栏 | 视口的菜单。放不下时可以滚动。 | 鼠标滚轮，或用手指拖动。 |
| 用键盘打开菜单栏 | 打开活动视口的菜单栏，用方向键浏览。 | <kbd>M</kbd>（在 Edit Mode 中，<kbd>M</kbd> 是 Merge）。 |
| Undo / Redo | 撤销或重做上一个操作。 | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> 或 <kbd>Ctrl+Shift+Z</kbd>；也可用底部栏的箭头。 |
| Save project | 保存当前打开的 .w3d（如果是新项目，会要求你输入名称）。 | <kbd>Ctrl+S</kbd>，或 Properties → File/Render 选项卡 → File 卡片（参见[项目](proyecto.md)）。 |
| Fullscreen | 进入或退出全屏。 | <kbd>F11</kbd>。在 Android 上，如果手机没有刘海，会自动全屏。 |
| Play / Pause | 在任意面板中播放动画（或游戏）。 | <kbd>Space</kbd>，或 Timeline 上的 Play 按钮。 |

**在 Android 上**：竖屏时，布局是上方 3D Viewport、下方 Properties；横屏时还会加上 Timeline。打开屏幕键盘时（例如在 Script Editor 中），活动视口会在可见区域内最大化，关闭键盘后再回到原位。
