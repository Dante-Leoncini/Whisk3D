# 修改器

修改器在 Properties 中添加（Modifiers 卡片 → Add），它们会改变网格但不会破坏原网格：你可以随时关闭、重新排序或应用（烘焙）它们。

| 修改器 | 说明 |
|---|---|
| Mirror | 沿 X、Y 和/或 Z 镜像网格（也可以相对于另一个对象）。可以焊接中心，并防止两侧互相穿插。 |
| Array | 成排复制：数量、相对偏移（按尺寸）、恒定偏移（以米为单位），还可以选择按另一个对象偏移（累积效果：螺旋、楼梯）。可以把各个副本焊接起来。 |
| Subdivision Surface | 通过细分让网格更平滑（视图和渲染分别设置级别）。 |
| Boolean | 与另一个对象求交集、并集或差集。 |
| Screw | 让一个轮廓绕某个轴旋转（螺丝、花瓶、弹簧）。 |
| Armature | 用骨架使网格变形。 |
| Culling | 优化：不绘制从相机看不到的部分。 |
