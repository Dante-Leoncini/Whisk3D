# Whisk3D 是什么

Whisk3D 是一款从零开始打造的 3D 编辑器和游戏引擎。你可以用它建模、绘制、制作动画、搭建 2D 界面，并用 Lua 编写游戏。它可以运行在 **PC**（Linux、Windows）、**Android**、**浏览器**（Web）和 **Nokia N95**（Symbian）上。

所有工作都保存在一个 `.w3d` 项目文件中。文件里既有场景，也有各种资源：纹理（`texturas/`）、脚本（`scripts/`）、声音、场景、预制体（prefab）。资源可以存放在 .w3d **内部**，也可以作为磁盘上的独立文件存放在**外部**；“Save inside the .w3d”和“Save outside the .w3d”菜单可以把资源在两者之间移动。

> [!NOTE]
> 本手册介绍的是 Whisk3D 目前已有的功能。由于编辑器暂时还没有中文版，手册中的功能名称都是编辑器英文界面中显示的名称。手册中列出的按键均为默认设置，你可以在[键盘快捷键](atajos.md)中修改。
